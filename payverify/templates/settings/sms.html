Forward bank SMS automatically

When your bank texts you “Rs 500 credited … UPI Ref 6278…”, your phone sends that SMS to the link below. Screenshots with the same UTR and amount then become Verified by themselves.

Which senders to trust

Banks send alerts from names like AX-HDFCBK, never from a normal phone number, so SMS from phone numbers are always ignored. This stops someone texting you a fake “credited” message.

Comma separated. Leave empty to accept any bank-style sender name.

{{ icon('phone') }}Android setup
  1. Install an SMS-to-webhook forwarding app, for example the open-source SMS Forwarder (search “SMS forwarder webhook” in the Play Store).
  2. Create a rule that forwards SMS whose sender contains your bank's name (for example HDFCBK).
  3. Set the URL to your private forwarding link, the method to POST, and the JSON body to: 
    {"from": "%from%", "text": "%text%"}
    (use the app's own placeholders for sender and message text).
  4. Allow the app to run in the background and turn off battery optimisation for it, or it may stop forwarding.
{{ icon('phone') }}iPhone setup (Shortcuts)
  1. Open Shortcuts → Automation → New Automation → Message.
  2. Choose Message Contains “credited” (and/or your bank as the sender), then Run Immediately.
  3. Add the action Get Contents of URL: paste your private link, set Method to POST, Request Body to JSON, and add two text fields: from = the message's Sender and text = the message's Content.

No phone forwarding? Paste SMS or import your bank statement on the Bank screen instead.
